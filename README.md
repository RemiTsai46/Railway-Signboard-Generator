# Railway-Signboard-Generator
A railway signboard generator for RoFT maps.

Unfinished project, bugs might occur.

Please use pillow 10.3.0 or above for compatibility (PIL._typing.Coords requires it).

## Usage
Put your desired data into `dataInput_#XXX` files and run it, you will get the output in `output.png`. You may also try the extra tools I made.
